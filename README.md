# SHf_SmartPickup — мод подбора предметов для SILENT HILL f

Lua-мод для UE4SS. Движок игры: Unreal Engine 5.4.2, игровой модуль `GameNoce`.

## Что делает

1. **Замена оружия при полном инвентаре.** После выбора в диалоге «заменить оружие»
   выброшенное оружие появляется на земле ровно там, где лежало новое, и сохраняет
   свою прочность (прочность восстанавливается в момент повторного подбора).
2. **Расходник при полном инвентаре расходников.** Правило намеренно простое:
   * предложение появляется только для **одиночного** предмета на земле (стак из 2+ штук,
     например выложенный этим же модом, всегда идёт в обычный диалог замены);
   * предмет должен иметь собственный эффект (подношения FaithA/B/C не предлагаются);
   * когда предлагать, задаёт `InstantUse` в `Scripts/main.lua` (значения из таблицы `InstantUseMode`):
     `Useful` (по умолчанию) — только если предмет полезен сейчас (здоровье/рассудок/выносливость
     ниже максимума по проверке игры `CanUseConsumableType` или по атрибутам игрока);
     `Always` — предлагать и при полных показателях (набор инструментов по-прежнему только
     при повреждённом оружии); `Off` — не предлагать, всегда обычный диалог замены;
   * показывается стандартный диалог игры (`WBP_PopWindow`): «Инвентарь полон.
     Использовать «<предмет>» сейчас?» с кнопками «Подтвердить / Отмена» (по умолчанию «Отмена»).
   **Подтвердить** — расходуется ровно одна единица, предмет с земли исчезает, содержимое
   инвентаря не меняется (если такой предмет уже есть, используется один из инвентаря и
   подбирается новый; если нет — эффект применяется напрямую, для набора инструментов это ремонт
   экипированного оружия на половину максимума). **Отмена** — обычный диалог замены.
   Без вопроса (применять молча) — `ConfirmInstantUse = false`.
3. **Замена расходников при полном инвентаре.** Выброшенный стак появляется на земле
   там, где лежал новый предмет. Режим задаёт `SeparateDropsUpTo` в `Scripts/main.lua`:
   * `0` (по умолчанию) — один предмет, который даёт весь стак при подборе.
     Игра сама поддерживает это через поле `Count` у актора подбора, поэтому вариант
     самый надёжный и совместим с диалогом замены при повторном подборе.
   * `N` — по одному предмету на штуку, не больше N, выкладываются рядом с шагом
     `DropSpacing` (25 см); остаток уходит в последний предмет.

## Установка

Требуется UE4SS **experimental** (релиз `experimental-latest`, 3.0.1-1181 и новее) с
официальным игровым конфигом «Silent Hill F» из `zCustomGameConfigs.zip`
(`MemberVariableLayout.ini` + `UE4SS-settings.ini`). Без него UE4SS на этой игре падает.

Структура в папке игры:

```
SHf/Binaries/Win64/dwmapi.dll
SHf/Binaries/Win64/ue4ss/UE4SS.dll
SHf/Binaries/Win64/ue4ss/UE4SS-settings.ini      (из конфига Silent Hill F)
SHf/Binaries/Win64/ue4ss/MemberVariableLayout.ini (из конфига Silent Hill F)
SHf/Binaries/Win64/ue4ss/Mods/SHf_SmartPickup/Scripts/main.lua
SHf/Binaries/Win64/ue4ss/Mods/mods.txt            (строка "SHf_SmartPickup : 1" выше блока Keybinds)
```

В этой копии игры всё уже установлено. SHfFix (`dsound.dll` + `SHfFix.asi`) сосуществует с UE4SS —
это разные proxy-DLL.

## Как проверить в игре

Включён вывод в консоль UE4SS (`ConsoleEnabled = 1` в `UE4SS-settings.ini`) и `Debug = true`
в моде. Все действия мода пишутся с префиксом `[SHf_SmartPickup]` в консоль и в
`SHf/Binaries/Win64/ue4ss/UE4SS.log`.

1. Загрузить сохранение, набрать 3 оружия (трубу, нож, серп и т.п. — только то, что игра
   разрешает выбрасывать: Pipe, Dagger, Sickle, Axe, Bat, Crowbar, Hammer).
2. Подойти к четвёртому оружию, выбрать замену. Ожидаемо: старое оружие лежит на месте нового,
   в логе `Dropped weapon ... (durability N)`. Подобрать его обратно — в логе
   `Restored durability ...`, прочность как была.
3. Заполнить слоты расходников, получить урон, подойти к аптечке/еде. Ожидаемо: предмет
   применяется, диалога замены нет (`Inventory full: used ...`).
4. При полном инвентаре подобрать неподходящий сейчас предмет и заменить им стак —
   выброшенный стак лежит рядом (`Dropped a stack of N x ...`).

Проверено в игре (25.10.2026): выкладывание заменённых стаков, диалог «использовать сейчас»,
применение эффектов через систему способностей (`BP_ApplyGameplayEffectToSelf`), распознавание
ответа по `List.SelectingIndex`. Не проверено: замена оружия с выкладыванием и восстановление
прочности, раскладка по одному (`SeparateDropsUpTo > 0`), режим `InstantUse = Always`,
ремонт набором инструментов при полном инвентаре.

## Ограничения

* Выложенные предметы — динамические акторы: они не попадают в сохранение и исчезнут
  при перезагрузке уровня/сейва. Это осознанно: сериализация в `NoceItemSubsystem` не трогалась.
* Оружие, которое игра запрещает выбрасывать (Katana, Naginata, Lantern, Kaiken, ToySaber),
  диалог замены не вызывает — мод на него не влияет.
* Прочность выброшенного оружия хранится в памяти мода до его подбора в этой сессии.

## Технические заметки

* В этой игре UE4SS **не вызывает post-хуки** на Blueprint-функциях — используются только pre-хуки.
  Разница инвентаря считается в pre-хуке `HandlePickupSuccess` (игра вызывает его после обмена).
  Чтобы Blueprint не открыл диалог замены, мод на 60 мс обнуляет `ReplaceConsumableUIPath`.
* Структуры, возвращаемые UFunction (например `GetConsumableData`), приходят в Lua обычными таблицами;
  обратно в игру такую таблицу как `TArray<FSoftClassPath>` передать нельзя, поэтому пути классов эффектов
  зашиты в мод. Пустая таблица `{}` для `FGameplayEffectContextHandle` принимается.
* `UseConsumable` компонента инвентаря только списывает предмет; эффект накладывает способность
  использования, поэтому мод накладывает `GameplayEffect`-классы сам.
* Страховка от зависшей паузы (`ForceUnpauseFallback`) выключена: окно показа подобранного предмета
  тоже ставит паузу и не отличимо от зависания.
* Хуки ставятся на Blueprint-функции `BP_Interact_Pickup_C`:
  `ShowReplaceWeapon` (pre, снимок инвентаря), `OnReplaceWeaponUIEnd` (post, diff → спавн),
  `NeedShowReplaceConsumableUI` (post, подмена out-параметра), `ShowReplaceConsumableUI` (pre),
  `OnReplaceConsumableUIEnd` (post), `HandlePickupSuccess` (post, восстановление прочности).
* Спавн — `World:SpawnActor(BP_Interact_Pickup_Wep_<Row>_C | BP_Interact_Pickup_Con_<Row>_C, loc, rot)`.
  Имена строк таблиц `DT_WeaponItem` / `DT_ConsumableItem` совпадают с суффиксами классов.
* Инвентарь: `UNocePlayerInventoryComponent` (`FogWeapons`/`DarkWeapons` — массивы
  `{IDIndex, Durability}`, `Consumables` — `{IDIndex, Quantity}`, `AllWeaponIDs`/`AllConsumableIDs` — имена по индексу).
* Инструменты и дампы лежат в `_modding/`: `retoc`, `repak`, `UAssetGUI` (+ .NET 8 Desktop Runtime),
  `tools/lua` (Lua 5.4.2: `luac54.exe -p Scripts/main.lua` проверяет синтаксис мода без запуска игры),
  `SHf.usmap` (дамп UE4SS), `ObjectDump.txt`, `sdk_inventory.txt` (классы инвентаря),
  `decomp_BP_Interact_Pickup.txt` (псевдокод Blueprint), `kismet_dump.py` (конвертер bytecode из JSON UAssetGUI).
